Spring Boot RESTful API

Sütemény REST API

A REST API JSON adatokat kezel. A GET műveletek nyilvánosak, a POST/PUT/DELETE műveletekhez ADMIN szerepkör szükséges.

HTTP metódusÚtvonalFunkcióJogosultság
GET/api/sutikÖsszes süteményPublikus
GET/api/sutik/{id}Egy süteményPublikus
POST/api/sutikÚj süteményADMIN
PUT/api/sutik/{id}Meglévő módosításaADMIN
DELETE/api/sutik/{id}Sütemény törléseADMIN

GET /api/sutik kipróbálása

POST/PUT/DELETE: JSON törzs, HTTP Basic belépés. Teszt Postmanben és cURL-lel, dokumentált képernyőképekkel.
